# 可配置应用运行框架

Go 包 appruntime 提供模块注册、依赖排序、配置校验、资源准备、原子版本发布和统一收尾。

## 生命周期

- 启动和热切换按依赖拓扑顺序校验并准备资源。
- 新版本所有资源准备成功后才原子替换当前版本。
- 准备或持久化失败时关闭已创建的新资源，旧版本继续服务。
- 工作通过 Framework.Current 获取不可变 Snapshot，完成后必须调用 Done。
- 旧版本在所有在途 Snapshot 释放后，按依赖逆序关闭资源。
- 成功发布的配置通过临时文件加原子重命名持久化；重启调用 Load 加载最后成功版本。

## 验证

运行：
